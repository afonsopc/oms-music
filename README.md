# OMS Music

The omelhorsite music app: library, player, offline downloads, lyrics, jams —
one React Native codebase for iOS, Android, web and desktop, talking to the
same backend as [omelhorsite.pt](https://omelhorsite.pt).

## Use it

- **Web** — [music.omelhorsite.pt](https://music.omelhorsite.pt)
- **iOS · Android · macOS · Linux** — grab a build from the
  [releases](https://github.com/afonsopc/oms-music/releases)

## Hack on it

```bash
bun install
bunx expo run:ios      # or run:android
```

Expo SDK 57, TypeScript strict, bun. Toolchain gotchas, checks and how the app
is put together: [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md). The spec and
architecture live in [docs/](docs) — start with `SPEC.md` and `DESIGN.md`.

Desktop shell: [desktop/](desktop). Display face: OMS Wide, ours, generated by
[`scripts/generate-oms-wide.py`](scripts/generate-oms-wide.py) (OFL 1.1).
