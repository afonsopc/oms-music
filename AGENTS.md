# Sem branches

Trabalha sempre em `master`, directamente. Este repo é pequeno e é de uma
pessoa só: um branch por feature só acrescenta merges, worktrees presos e
builds a sair da árvore errada, sem nada em troca.

# Commit implica push

Depois de commitar, dá `git push` sempre (dono, 2026-08-22). Commits só
locais não são hábito nenhum nesta casa: o que está feito sobe.
